# 📚 NCERT Class 1 Multilingual Textbook Corpus

This directory contains the primary foundational learning material for Class 1 under the National Council of Educational Research and Training (NCERT) curriculum in multiple regional Indian languages.

## 🗂️ Language & Subject Breakdown

| Language | Subject | Source Files | Description |
|---|---|---|---|
| **English** | Marigold (English) | `aemr101.pdf` – `aemr109.pdf`, `aemr1ps.pdf` | Foundational vocabulary, stories, rhyming poems, phonetics |
| **Bengali** | Ananda Ganit (Maths) | `abnjm101.pdf` – `abnjm113.pdf`, `abnjm1ps.pdf` | Class 1 Mathematics translated into Bengali script |
| **English** | Joyful Mathematics | `aejm101.pdf` – `aejm113.pdf`, `aejm1ps.pdf` | English-medium foundational numeracy, shapes, patterns |
| **Hindi** | Anandmay Ganit (Maths) | `ahjm101.pdf` – `ahjm113.pdf`, `ahjm1ps.pdf` | Hindi-medium numbers 1–99, basic addition, subtraction |
| **Tamil** | Ganitham (Maths) | `atmjm101.pdf` – `atmjm113.pdf`, `atmjm1ps.pdf` | Tamil-medium Class 1 mathematics curriculum |
| **Telugu** | Ganitham (Maths) | `atljm101.pdf` – `atljm113.pdf`, `atljm1ps.pdf` | Telugu-medium foundational numeracy & spatial concepts |

## 🎯 Usage in Vidya Mitra

1. **RAG Knowledge Base**: Extracted text chunks and metadata (Class: 1, Subject, Chapter, Language) are indexed in ChromaDB vector store.
2. **Parallel Indic Alignment**: Parallel chapters across Bengali, Hindi, Tamil, Telugu, and English are utilized for bilingual sentence alignment and Indic translation evaluation.
3. **Socratic Example Synthesis**: Visual problems from these textbooks are converted into multi-step interactive micro-lessons and progressive hints for young learners.
